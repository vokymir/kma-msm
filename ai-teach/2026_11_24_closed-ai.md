- [Dimension Reduction Methods](#dimension-reduction-methods)  
  - **Principal Component Analysis (PCA)**  
    - Goal: find orthogonal axes (principal components) capturing maximal variance in the data.  
    - Procedure:
      1. Center the data (subtract the mean vector) and optionally scale (see below).  
      2. Compute the covariance matrix $S$ of the variables.  
      3. Solve the eigen-decomposition $S v = \lambda v$ to find eigenvalues $\lambda_1\ge\lambda_2\ge\cdots$ and eigenvectors $v_i$. These eigenvectors are the principal component directions.  
      4. Project the data onto the top eigenvectors to get principal component scores.  
    - Interpretation:
      - The first principal component (PC1) is the direction of greatest variance; the second (PC2) is orthogonal to the first and explains the next-most variance, and so on.  
      - The eigenvalues indicate the variance explained by each PC. Scree plots (variance vs. component index) help choose how many PCs to keep.  
      - In practice, the first two or three PCs often suffice to capture most structure and allow 2D/3D visualization.  
    - Why PCA works:
      - Geometric intuition: PCA fits an ellipsoid to the data; each axis of the ellipsoid is a PC with length proportional to data spread.  
      - Algebraic: PCs solve an optimization to maximize variance under orthogonality constraints. Equivalently, PCA diagonalizes the covariance matrix so off-diagonal covariances vanish.  
    - Computation:
      - PCA by eigen-decomposition of $S$ or equivalently via singular value decomposition (SVD) of the data matrix.  
      - Numerical issues: for large $p$ or near-singular $S$, use SVD or robust methods.  
    - Assumptions and Caveats:
      - PCA assumes linear relationships and uses Euclidean distance. It is sensitive to scaling of variables: features with large variance dominate the PCs. (Standardize variables to unit variance if they are on different scales.)  
      - PCA assumes data are continuous. Nonlinear relationships may require extensions (kernel PCA, manifold learning).  
      - Outliers can heavily influence PCs. Robust PCA variants exist.  
    - Connections:
      - PCA is closely related to factor analysis (see below) and to singular value decomposition in linear algebra. It is widely used for pre-processing in machine learning, pattern recognition, and image compression. It reduces dimensionality while preserving as much variance (information) as possible.  
    - Example:
      - For a 2-variable dataset with covariance matrix $S=\begin{pmatrix}4 & 2\\2 & 3\end{pmatrix}$, compute its eigenvalues and eigenvectors, and show the principal axes and projected data.  
    - Related Methods:
      - **Factor Analysis** (see below) also reduces dimensionality but with a statistical model (latent factors).  
  - **Factor Analysis (FA)**  
    - Unlike PCA, FA assumes an explicit generative model: each observed variable is a linear combination of a few underlying *latent factors* plus noise.  
    - Model: $X = LF + \epsilon$ where $X$ (observations) depends on $k$ latent factors $F$ via loadings matrix $L$, plus error ε.  
    - The goal is to explain covariances among observed variables by fewer factors (e.g., 6 observed variables from 2 common factors). The factors are unobserved; their *loadings* indicate how strongly each variable depends on a factor.  
    - Unlike PCA, FA explicitly models variances (unique variances vs. common variance) and often involves fitting (e.g. maximum likelihood or principal axis factoring). Rotation methods (e.g. varimax) make factors more interpretable.  
    - FA is common in psychometrics, social sciences, and whenever latent constructs are hypothesized.  
    - The distinction from PCA: PCA is purely geometric (maximizing variance), whereas FA assumes a statistical model with measurement errors. In PCA, all variability is captured; in FA, only *shared* variability is modeled by factors, and unique variances remain.  
    - Example: Survey data on personality traits might be explained by latent “Big Five” factors using factor analysis.  
    - [*For brevity, this guide focuses on PCA; factor analysis can be studied in specialized texts.*]

## Computer Science and ML Connections

- **Data Structures and Operations:**  Multivariate data can be stored as matrices (each row an observation, each column a variable). Basic operations (dot products, matrix multiplication) are key. For large datasets, sparse or distributed matrices and efficient BLAS/LAPACK routines are used.

- **Numerical Linear Algebra:**  Eigenvalue decomposition and singular value decomposition (SVD) are fundamental computational tools (PCA uses them). Efficient algorithms (power iteration, Lanczos, randomized SVD) allow PCA on large matrices.

- **Algorithms and Complexity:**  Many multivariate methods involve polynomial-time linear algebra (e.g. PCA is $O(np^2)$ for covariance eigen-decomposition, or $O(np\min(n,p))$ for SVD). Clustering (like k-means) is iterative and often $O(nkp)$ per iteration. Awareness of complexity guides method choice for big data.

- **Optimization:**  Certain methods (e.g. k-means clustering) solve objective functions (minimize within-cluster variance) often via iterative optimization (EM-like updates). PCA solves an eigenproblem equivalent to optimizing variance explained.

- **Machine Learning Context:**  
  - PCA is an unsupervised dimensionality reduction widely used in ML pipelines for feature extraction and noise reduction.  
  - LDA (Linear Discriminant Analysis) can also be seen as a linear classifier (it finds a projection that best separates classes).  
  - Clustering methods (k-means, hierarchical) are fundamental unsupervised learning algorithms for finding structure in data, used in tasks like image segmentation or document clustering.  
  - Many ML models (e.g. Gaussian Mixture Models) generalize ideas of multivariate normal and clustering.

- **Statistical vs Algorithmic Perspective:**  Traditional multivariate stats emphasizes distributional assumptions (e.g. normality) and hypothesis testing, whereas CS/ML often focus on algorithms and prediction. Both perspectives are valuable: e.g. MANOVA tests depend on normality, but clustering or PCA can be applied more algorithmically on any data.

## Multivariate Data and Visualization

- A multivariate dataset is often represented as an $n\times p$ **data matrix** $X$, with $n$ observations (rows) and $p$ variables/features (columns). Each observation is a point in $\mathbb{R}^p$.  
- The **sample mean vector** $\bar{x}$ is the element-wise mean of each column (feature). Each element $\bar{x}_i$ is the average of variable $i$ over all observations.  
- The **sample covariance matrix** $S$ (or $\Sigma$) is a $p\times p$ matrix where $S_{ij} = \frac{1}{n-1}\sum_{k=1}^n (X_{k,i}-\bar{x}_i)(X_{k,j}-\bar{x}_j)$. Intuitively, $S_{ij}$ measures how variables $i$ and $j$ co-vary.  
  - As a definition: *“In probability theory and statistics, a covariance matrix is a square matrix giving the covariance between each pair of elements of a given random vector.”*.  
  - Geometric interpretation: if you plot points in 2D (variables $x$ and $y$), the direction of greatest spread is indicated by the largest eigenvector of $S$, and the corresponding eigenvalue is the variance in that direction.  
- A related concept is the **correlation matrix**, which is the covariance matrix of standardized (mean 0, variance 1) variables. Correlations are dimensionless measures of linear association. Using correlation instead of covariance in PCA yields *Principal Components of standardized data* (often called using *“correlation PCA”*).  
- **Visualization:**  Scatterplot matrices (pairwise plots), 3D scatter plots, and parallel-coordinate plots help visualize multivariate data for small $p$.  PCA provides 2D or 3D projections (scores on first PCs) for visualizing high-dimensional data.  

## Cluster Analysis

**Cluster analysis** (clustering) is the task of grouping a set of objects so that objects in the same group (cluster) are more similar to each other than to those in other groups. It is fundamentally exploratory: clusters are not known beforehand (unlike classification).  

- The definition: *“Cluster analysis … is a data analysis technique aimed at partitioning a set of objects into groups such that objects within the same group … exhibit greater similarity to one another (in some sense defined by the analyst) than to those in other groups.”*.  
- **Goals and Notions of Similarity:**  Similarity can be measured by distance (e.g. Euclidean) or other notions. Common cluster models include:
  - *Connectivity-based (hierarchical) clustering*: build a hierarchy by merging/splitting based on distance connectivity (e.g. single-linkage, complete-linkage).
  - *Centroid-based (k-means) clustering*: represent each cluster by its mean; iteratively assign points to nearest centroid and update centroids.
  - *Distribution-based clustering*: assume each cluster is a statistical distribution (e.g. Gaussian mixtures) and fit via EM.
  - *Density-based clustering*: find clusters as dense regions separated by low-density (e.g. DBSCAN, OPTICS).  
- **K-Means Clustering (Example Algorithm):** Choose $k$ cluster centers, assign each point to nearest center, recompute centers as group means, repeat. This minimizes the total within-cluster sum-of-squares. It converges to a local optimum; multiple random restarts are often used. It requires choosing $k$ in advance.  
- **Hierarchical Clustering:** Builds a tree (dendrogram) of clusters. *Agglomerative* starts with each point alone and merges closest clusters step-by-step. *Divisive* splits from one cluster to many. Hierarchical methods do not require $k$ upfront; one can “cut” the dendrogram to choose a clustering.  
- **Cluster Evaluation:** Unlike supervised learning, clustering has no single ground truth. Methods include silhouette scores, elbow plots of within-cluster variance vs $k$, or cross-validation of clustering stability.  
- **Assumptions & Caveats:** Clustering has no strict statistical assumptions but depends on the similarity measure and algorithm. For example, k-means assumes spherical clusters of similar size (it uses Euclidean distance). If data has outliers or irregular shapes, different algorithms (e.g. DBSCAN) may be better. Feature scaling is crucial (variables on different scales can distort distance measures).  
- **Common Use-Cases:** Market segmentation, image segmentation, document grouping, anomaly detection (as clusters plus outliers).  
- **Citation:** Clustering **“refers to a family of algorithms”** rather than a single method. The wiki notes *“Clustering can therefore be formulated as a multi-objective optimization problem”* (balancing intra-cluster similarity and inter-cluster differences).  
- **Example:** Given 2D points, we can visually show how k-means partitions them into clusters by proximity. For instance, cluster the points \{(1,1), (1,2), (5,5), (6,5)\} into $k=2$ clusters.  
- **Alternatives and Failures:** If data violate k-means assumptions (non-globular clusters, noise), one may use hierarchical clustering or density-based methods. If distance measure is ambiguous (mixed categorical and numerical data), specialized algorithms are needed.

## Linear Discriminant Analysis (LDA)

**Discriminant analysis** refers to methods for classifying observations into known groups based on predictor variables. In **Linear Discriminant Analysis (LDA)**, the goal is to find a linear combination of features that best separates two or more classes. Unlike clustering (groups unknown a priori), here group labels are known for the training data.

- **LDA Concept:** *“Discriminant analysis is used when groups are known a priori… each case must have a score on quantitative predictors and a group measure. In simple terms, discriminant function analysis is classification — the act of distributing things into groups, classes or categories”*.  
- **Two-Class LDA (Fisher’s LDA):**  For two groups, LDA finds a line (or hyperplane) that best separates the classes. Formally, assume each class has multivariate normal distribution with a common covariance matrix $\Sigma$ (homoscedasticity). The log-ratio of class-conditional densities leads to a linear decision rule: an observation $\mathbf{x}$ is classified to class 1 if $\mathbf{w}^T\mathbf{x} > c$, where $\mathbf{w} = \Sigma^{-1}(\mu_1 - \mu_0)$ and $c$ is a threshold. Geometrically, this says we project data onto $\mathbf{w}$ (a direction orthogonal to the decision boundary) and choose the side of the hyperplane.  
- **LDA vs Other Methods:**  
  - Unlike PCA, LDA explicitly uses class labels (maximizes class separation), whereas PCA ignores them.  
  - If class covariances differ significantly, *Quadratic Discriminant Analysis (QDA)* is a more flexible alternative (it allows a quadratic decision boundary).  
  - Compared to logistic regression (a discriminative classifier), LDA is generative (models data distributions), often giving similar results if assumptions hold.  
- **Assumptions:**  LDA assumes (i) multivariate normality of predictors within each class, and (ii) equal covariance matrices across classes (homoscedasticity). It is sensitive to outliers and requires that the number of predictors be less than group sizes to avoid singular covariance. These are similar to MANOVA’s assumptions. In practice, LDA often works well even if some assumptions are mildly violated, but one should check scatterplots and test for normality or use regularized versions if needed.  
- **Interpretation:**  The vector $\mathbf{w}$ provides insight into which features most discriminate the classes. A large coefficient (in absolute value) in $\mathbf{w}$ means that feature heavily influences classification.  
- **Connections:**  LDA is essentially a maximum-margin classifier under Gaussian assumptions. In the CS context, LDA can be derived from solving a generalized eigenvalue problem (between-class vs within-class scatter) – an eigenvalue problem similar to PCA but with covariance split by class.  
- **Example:**  Suppose two groups of points in 2D: Group A centered at $(1,1)$ and Group B at $(4,4)$, both with identity covariance. Compute $\mathbf{w}$ and show the decision boundary (a line halfway between means).  
- **Citation:** LDA *“explicitly attempts to model the difference between the classes of data.”* It contrasts PCA and factor analysis, which look at variance and similarity rather than class separation.

## Step-by-Step Method Summaries

We give **plain-language step-by-step outlines** of key methods:

- **PCA Step-by-Step:**  
  1. **Center the data.** Subtract the mean $\bar{x}$ from each observation so that each column has mean zero. (If variables have vastly different scales, scale to unit variance.)  
  2. **Compute covariance.** Calculate $S = \frac{1}{n-1}X^T X$ where $X$ is the centered data matrix.  
  3. **Eigen-decompose.** Solve $S v_i = \lambda_i v_i$. Sort eigenvalues $\lambda_1\ge\lambda_2\ge\cdots\ge\lambda_p$. The eigenvector $v_1$ gives PC1 (max variance), etc. These $v_i$ are orthonormal basis vectors in feature space.  
  4. **Project data.** For each $i$-th principal component, compute scores $z_i = X v_i$. These are the coordinates of data in the PC space. Often we use just the first $k$ scores (dimension reduction).  
  5. **Interpret and select.** Examine the variance explained by each PC ($\lambda_i$) and plot (scree). Keep the smallest number of PCs that explain a large fraction (say 90%) of the variance.  
  6. **Diagnose.** Check if PCA assumptions hold: Are variables roughly linear? Are there outliers? If not, consider robust PCA methods.  
  7. **Result Interpretation.** Each PC is a linear combination of original variables. For instance, PC1 might be $0.6x_1 + 0.8x_2$ (if 2D data). Variables with large coefficients contribute most to that component.

- **Factor Analysis Step-by-Step (brief):**  
  1. **Choose # factors.** Decide on number $k$ of latent factors (often via a scree plot on initial eigenvalues).  
  2. **Estimate loadings.** Use methods (e.g. principal axis factoring) to find a $p\times k$ loadings matrix $L$ and unique variances $\psi_i$ that model the covariance $S \approx LL^T + \Psi$.  
  3. **Rotate factors (if desired).** Apply orthogonal (varimax) or oblique rotations to $L$ for interpretability (so that each factor loads strongly on a few variables).  
  4. **Interpret factors.** Look at which variables load on which factor to name them (e.g. “size” vs “shape” factor).  
  5. **Compute factor scores.** Optionally, compute scores of observations on factors (like we did for PCs).

- **Hotelling’s T² Test Step-by-Step:**  
  1. **Compute sample mean $\bar{x}$ and covariance $S$** from your $n$ observations of a $p$-variate dataset.  
  2. **Formulate $H_0$.** E.g. $H_0: \mu = \mu_0$ (a hypothesized mean vector).  
  3. **Compute statistic:** $T^2 = n(\bar{x}-\mu_0)^T S^{-1}(\bar{x}-\mu_0)$.  
  4. **Determine threshold:** Under $H_0$, $(n-p)/(p(n-1))T^2 \sim F_{p,n-p}$, so reject $H_0$ if $T^2$ exceeds the critical value from the $F$-distribution.  
  5. **Interpret:** If $H_0$ is rejected, conclude the mean vector significantly differs from $\mu_0$ in at least one direction. Inspect the direction $(\bar{x}-\mu_0)$ to see which variables contribute most.

- **MANOVA Step-by-Step:**  
  1. **Collect data** with multiple outcome variables across groups (e.g. outcomes $Y$ and group labels).  
  2. **Compute within-group scatter $W$ and between-group scatter $B$** (matrix analogues of sums of squares).  
  3. **Calculate Wilks’ Lambda or other criterion:** $\Lambda = \det(W) / \det(W+B)$. Small $\Lambda$ suggests group means differ.  
  4. **Find significance:** Convert $\Lambda$ to an $F$-statistic (software does this) to test $H_0$: all group mean vectors are equal.  
  5. **Post-hoc:** If significant, run follow-up (univariate ANOVAs or pairwise discriminant analysis) to see which variables or groups differ.  
  6. **Assumptions:** Verify multivariate normality (Q-Q plots of joint distribution), covariance equality (Box’s M test), no multicollinearity (variance inflation factors).

- **Cluster Analysis (K-means) Step-by-Step:**  
  1. **Decide number of clusters $k$** (by domain knowledge or elbow method).  
  2. **Initialize $k$ centroids** (randomly pick $k$ points or use k-means++ initialization).  
  3. **Assign points to clusters:** For each data point, assign it to the cluster with the nearest centroid (using Euclidean distance).  
  4. **Update centroids:** Recompute each cluster’s centroid as the mean of points assigned to it.  
  5. **Iterate:** Repeat assignment and update until cluster assignments stabilize (or a max iteration is reached).  
  6. **Result:** Each point has a cluster label. Examine intra-cluster variance; optionally try different $k$ or initializations.  
  7. **Evaluate:** Compute total within-cluster sum-of-squares or silhouette scores to assess quality.  
  8. **Interpretation:** Inspect cluster centroids or representative members to label clusters meaningfully.  

- **LDA (Fisher’s) Step-by-Step:**  
  1. **Split data by class:** Collect means $\mu_0$ and $\mu_1$ (or $m$ classes $\mu_1,\ldots,\mu_m$) and common covariance $S$ (pooled across classes).  
  2. **Compute weights:** $\mathbf{w} = S^{-1}(\mu_1-\mu_0)$ (for two classes) – this gives the direction best separating the two means. For multiple classes, solve the generalized eigenproblem for between vs. within scatter matrices (often yielding at most $m-1$ discriminant axes).  
  3. **Project data:** Compute one-dimensional scores $z = \mathbf{w}^T x$. Determine threshold $c$ to separate classes (e.g. midpoint of projected means).  
  4. **Classify new points:** Given a new $\mathbf{x}$, compute $\mathbf{w}^T\mathbf{x}$ and see which side of $c$ it falls on (or which class centroid it’s closer to in the projected space).  
  5. **Assumptions Check:** Verify roughly normal class-conditional distributions and similar covariances. Check classification accuracy via cross-validation.  
  6. **Interpret:** Large $|\mathbf{w}_i|$ indicates feature $i$ is important for discrimination.  

## Worked Examples and Exercises

1. **Hotelling’s T² Example:** Suppose 5 observations of a 2D random vector: $(2,3), (1,2), (4,5), (3,3), (2,4)$. Test $H_0: \mu = (0,0)$ at $\alpha=0.05$.  
   *Solution Sketch:* Compute $\bar{x}=(2,3)$, sample covariance $S$, then $T^2 = 5(\bar{x}-0)^T S^{-1}(\bar{x}-0)$ and compare to $F_{2,3}$ critical value. One finds if $T^2$ exceeds threshold, reject $H_0$. (Detailed arithmetic omitted here.)  
2. **PCA Exercise:** Given data points $(1,0),(0,1),(-1,0),(0,-1)$ (a cross), find the principal components.  
   *Solution:* The covariance matrix is $\begin{pmatrix}1 & 0\\0 & 1\end{pmatrix}$. Its eigenvectors are along $(1,0)$ and $(0,1)$ (or any orthonormal basis). All directions have equal variance, so any orthonormal basis is valid. Usually PCA yields PC1=$x$-axis, PC2=$y$-axis.  
3. **K-means Clustering:** Data: $\{(1,1),(1,2),(4,4),(5,4)\}$ with $k=2$.  
   *Solution:* Initialize centroids, say $(1,1)$ and $(4,4)$. Assign clusters: cluster1: $(1,1),(1,2)$; cluster2: $(4,4),(5,4)$. Update centroids to $(1,1.5)$ and $(4.5,4)$. This stabilizes quickly; final clusters separate the small group from the large group.  
4. **LDA Classification:** Class A: $(0,0),(1,0)$; Class B: $(0,1),(1,1)$. Find the LDA rule.  
   *Solution:* Means $\mu_A=(0.5,0)$, $\mu_B=(0.5,1)$, common covariance (pooled) is $S= \begin{pmatrix}0.25&0\\0&0.25\end{pmatrix}$. Then $\mathbf{w}=S^{-1}(\mu_B-\mu_A)=(0,4)$.  Classification: project onto the vertical axis; threshold at $0.5$. So basically if $y<0.5$ predict A, else B.  

## Glossary

- **Random vector:** A vector of random variables. E.g. $(X_1,X_2,\dots,X_p)^T$ is a random vector of dimension $p$.  
- **Covariance $\operatorname{Cov}(X,Y)$:** Measures how two random variables vary together. For data, $S_{ij} = \frac{1}{n-1}\sum (x_{k,i}-\bar{x}_i)(x_{k,j}-\bar{x}_j)$.  
- **Covariance matrix ($\Sigma$ or $S$):** A $p\times p$ matrix of covariances between all pairs of variables. It generalizes variance to multiple dimensions. It is symmetric and (positive semi-)definite.  
- **Correlation:** Standardized covariance (Cov$/\sigma_i\sigma_j$); values in $[-1,1]$. A correlation matrix is symmetric with 1s on the diagonal.  
- **Principal Component (PC):** A direction (unit vector) along which data have maximal variance under orthogonality constraints. Found as an eigenvector of the covariance matrix.  
- **Eigenvalues/eigenvectors:** For a matrix $S$, vectors $v$ such that $Sv = \lambda v$. The scalar $\lambda$ is an eigenvalue. PCA uses eigen-decomposition of the covariance matrix.  
- **Mahalanobis distance:** Distance of a point $x$ from a distribution with mean $\mu$ and covariance $S$: $d^2 = (x-\mu)^T S^{-1}(x-\mu)$. Measures distance in units of standard deviation.  
- **MANOVA:** Multivariate extension of ANOVA (analysis of variance). Tests differences between group mean vectors when there are multiple outcome variables.  
- **LDA:** Linear Discriminant Analysis, a classification method that finds a linear boundary assuming normal class-conditional distributions.  
- **Eigenproblem in discrimination:** LDA for multiple classes solves $S_W^{-1}S_B v = \lambda v$, where $S_W$ is within-class scatter and $S_B$ is between-class scatter (just as PCA solves $S v=\lambda v$).  

## Common Pitfalls & Advice

- **Skipping data centering:** PCA and many covariance-based methods assume the data are centered (zero mean). Always subtract the mean; failing to do so can give meaningless directions.  
- **Not scaling variables:** If variables are on different scales (e.g. centimeters vs. dollars), PCA will prioritize the high-variance scale. Use correlation-PCA (standardize features) if that’s inappropriate.  
- **Assuming normality blindly:** Many multivariate tests (LDA, T², MANOVA) assume multivariate normality. Check this with Q-Q plots or tests. If violated, nonparametric alternatives (like permutation tests) or robust estimates (robust covariance) should be considered.  
- **Over-interpreting PCA axes:** A high loading on a PC means correlation with that component, but the components themselves are linear mixes. Components have no inherent “label”; interpret with caution.  
- **Confusing clustering with classification:** Clusters are found without knowing true labels; they may not correspond to actual classes. Always validate clustering results (e.g. by domain knowledge).  
- **Linear assumptions:** LDA and PCA assume linear relationships. If data lie on a curved manifold, consider nonlinear methods (kernel PCA, manifold learning, or tree-based methods).  

## Learning Roadmap

1. **Refresh core math:** Ensure understanding of vectors, matrices, eigenvalues, and basic probability. (For example, remember that a covariance matrix is symmetric and use matrix algebra to compute it.)  
2. **Understand univariate stats first:** Be comfortable with means, variances, t-tests, and one-way ANOVA. Multivariate versions generalize these concepts.  
3. **Study covariance/correlation:** Learn how to compute and interpret the covariance matrix and correlation matrix in simple examples. Visualize with scatterplots.  
4. **Learn the multivariate normal:** Grasp how a joint normal distribution extends univariate normal (every linear combination is normal). Practice writing and reading the notation $X\sim \mathcal{N}(\mu,\Sigma)$.  
5. **Practice PCA on small data:** Do PCA by hand on a 2×2 covariance matrix; compute eigenvectors and project data. Use software (Python/R) to do PCA on a larger dataset (e.g., Iris dataset) and interpret the results.  
6. **Hands-on clustering:** Experiment with k-means and hierarchical clustering on toy data. Visualize the clusters and dendrograms.  
7. **Do classification examples:** Fit LDA and logistic regression on a simple 2D binary dataset. Compare decision boundaries. Explore how violating normality (e.g. use a circle vs. ellipse) affects LDA’s performance.  
8. **Work through an example MANOVA:** Perhaps using software, compare two groups on 3 response variables. Check outputs like Wilks’ lambda and understand what it means.  
9. **Solve exercises & problems:** Work through provided exercises and check solutions. Create your own examples or use real data to apply each method.  
10. **Read further with guidance:** If background in linear algebra is thin, consult references on eigen decomposition and matrix inversion (e.g., Strang’s *Introduction to Linear Algebra*). For probability refreshers, review univariate normal and chi-square distributions.
